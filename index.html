Engineering Case Studies & Architecture Notes

Architecting Nova Browser: Electron Multi-Process Isolation and Local MCP Server

The Problem: Desktop browsers frequently encounter high memory usage; integrating local Large Language Model (LLM) tooling often risks freezing the main UI thread and violating webview security sandboxing.

The Architectural Solution: Implemented a decoupled multi-process architecture with strict contextIsolation. Offloaded the Model Context Protocol (MCP) server to a dedicated lightweight Node.js background worker, bridging requests via secure asynchronous IPC channels. Tab synchronization utilizes PBKDF2 key derivation and AES-256-GCM encryption over real-time WebSockets.

Key Metrics: 30% lower RAM footprint, 0 ms UI thread freeze, zero-knowledge end-to-end encryption.

Zero-Allocation Game Loops & Draw Call Batching for WebGL (Unity URP)

The Problem: Browser-hosted WebAssembly games suffer from noticeable frame spikes during Garbage Collection (GC) passes and GPU pipeline stalls caused by redundant draw call dispatch.

The Architectural Solution: Refactored per-frame tick systems to strictly zero GC allocations using pre-allocated struct buffers and object pooling. Configured Unity's Scriptable Render Pipeline (SRP) batching and texture atlasing to compress complex 3D scenes down to 14 draw calls.

Key Metrics: Sustained 60 FPS in WebGL, 14 draw calls, 0 Bytes allocated per update frame.

Sub-4ms Low-Latency Audio Pipelines in Swift Core Audio

The Problem: Keyboard acoustic feedback feels disjointed if audio latency exceeds 10ms. Meanwhile, camera-based hand tracking can easily consume excessive CPU cycles and drain battery.

The Architectural Solution: Constructed custom circular PCM ring buffers directly leveraging Apple Core Audio and AVAudioEngine, achieving sub-4ms audio response. Throttled Apple Vision hand-pose detection to 30 FPS with downsampled monochrome frames, reducing idle CPU usage below 2%.

Key Metrics: < 3.8 ms audio latency, 15+ acoustic profiles, < 2.0% background CPU impact.
